# TableTap demo kit

Files
- index.html        demo hub (open this first when pitching)
- cafe.html / restaurant.html / bakery.html   the 3 customer menus
- cards.html        printable QR cards (customer QR + owner QR per demo)
- qr/owner-*.png    owner QR codes (open the price sheet directly)

Go live (5 minutes)
1. Upload this whole folder to Netlify Drop (app.netlify.com/drop), Cloudflare Pages or GitHub Pages.
2. In each of the 3 Google Sheets: Share > General access > "Anyone with the link" > Viewer.
   (Keep Editor access for owners only, by email.)
3. Open <your-site>/cards.html, paste the site URL in the box, print the customer QR cards.
